# metere

A native macOS menu bar application for audio level monitoring, Bluetooth device tracking, and auditory health statistics.

## Features

- **Menu Bar Audio Meter**: Real-time audio metering (dBFS and volume levels) directly from your macOS menu bar.
- **Bluetooth Device & Battery Tracking**: Monitors connected Bluetooth audio devices and displays battery levels.
- **Listening Sessions & Auditory Rest**: Tracks continuous listening time and promotes healthy auditory rest habits.
- **Detailed Statistics & History**: Insights into daily sound exposure, listening session distributions, and historical trends.
- **Native SwiftUI Design**: Built specifically for macOS with clean aesthetics and low system footprint.

## Requirements

- macOS 13.0 (Ventura) or later
- Xcode 15.0+ (for building from source)

## Getting Started

1. Open `metere.xcodeproj` in Xcode.
2. Select the `metere` target and your Mac as the run destination.
3. Build and run (⌘R).
